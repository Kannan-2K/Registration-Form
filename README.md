# Registration Form Validation

## 📌 Project Overview

This project is a simple and responsive Registration Form built using **HTML, CSS, and JavaScript**. It validates user input in real time and enables the Register button only when all fields meet the required validation rules.

## ✨ Features

- **Name Validation:** Ensures the name field is not empty.
- **Email Validation:** Checks whether the email address has a valid format.
- **Password Validation:** Requires a minimum of 6 characters.
- **Real-Time Validation:** Displays error messages while the user types.
- **Submit Button Control:** Keeps the Register button disabled until all fields are valid.
- **Success Message:** Displays a confirmation message after successful validation.
- **Responsive Design:** Provides a clean form layout for different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
